How it plays

  • Very Easy: two buttons, one correct answer.
  • Easy: four buttons, one correct answer.
  • Medium: eight buttons, one correct answer.
  • Hard: type the answer and use the in-game scrolling dropdown.
  • Very Hard: type the answer on a distorted flag, with no dropdown, no category hint and a 12 second limit.
  • Correct guesses mark flags complete in Mastery and remove them until the current selected set is complete.
